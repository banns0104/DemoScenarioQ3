🎬 어바웃피싱 8월 통합 — 대표님 시연 대본

test-platform.aboutfishing.kr · PC Chrome · 로그인 유지 상태 · 총 8~10분 · 2026-08-06 실측 검증 경로만 사용 (대본 그대로 진행 시 에러 화면 없음)

Ⅰ. 대표님이 조심해야 할 부분 — 한 장 요약

🚫 절대 클릭 금지 (누르면 에러·먹통이 그대로 보임)

  • 홈의 모든 프로모션: 상단 큰 배너 3장(웰컴 쿠폰팩/챔피언십/업데이트), 이벤트 ‘자세히 보기’, ‘10,000원 할인받고 예약하기’, ‘인천 태평호’ 광고, ‘이번 주 인기 어종’ 카드 → 전부 클릭해도 무반응
  • 선박 상세 맨 아래 ‘고객센터 바로가기’ → 전면 404 흰 화면 (복구 버튼 없음)
  • 항구(닻 아이콘) 시트의 ‘조황’ 탭 → 에러 문구 노출 (물때·선박·날씨 탭은 안전)
  • 통합검색 결과의 ‘선박조황’ 탭 → 본문에 \r\n 깨진 문자 노출 (업체 탭은 안전)
  • 검색 결과의 어종 카드(넙치) → 무반응
  • 마이페이지 ‘관심낚시 설정’·‘고객센터 바로가기’ → “준비 중입니다.” 토스트 / ‘회원탈퇴’·‘로그아웃’ 근처 금지
  • 예약 상세의 ‘예약취소’ → 홈 D-6 카드 데모 데이터가 날아감
  • 검색창에 “어바웃피싱호” 입력 금지 → 0건 나옴 (다른 선박은 정상)

⚠️ 조작 습관 (에러는 아니지만 시연 흐름 깨짐)

  • 새로고침(F5)·주소창 입력·브라우저 뒤로가기 금지 — 흰 화면이 수 초 뜸. 이동은 하단 GNB(새소식/탐색/출조/마이)와 화면 안의 ← 버튼만 사용
  • ESC로 팝업 닫기 안 됨 — 반드시 X 버튼. 검은 토스트가 X를 가리면 2~3초 기다렸다가 클릭
  • 결제 페이지 약관 행은 왼쪽 체크 영역을 클릭(오른쪽 ‘>’는 약관이 안 열리고 체크만 풀림)
  • 마지막 ‘162,000원 결제하기’ 버튼은 누르지 않고 멈춤 (실결제 방지)
  • 출조 탭에서 아래로 길게 스크롤 금지 — ‘실시간 조황’ 구간에 같은 선박(태진호) 카드 10장 연속 노출
  • 쭈갑 기획전은 첫 줄 4척까지만 — 두 번째 줄 ‘한빛낚시’ 대표사진이 버스 사진

Ⅱ. 시연 10분 전 준비 (진행자)

  1. 크롬에서 접속 → 로그인(광어홀릭) 확인 → 홈이 완전히 뜬 상태로 대기 (첫 로딩 흰 화면 수 초는 여기서 소진)
  2. 홈 바로가기 ‘선박조황’ 한 번 열어 사진이 정상인 조황 글 위치를 봐 둘 것 (이미지 서버 간헐 503 — 오늘은 최신글 사진 6장이 회색이었음). 확인 후 새소식 탭으로 복귀
  3. 창 크기 고정(전체화면 권장), 다른 탭·알림 정리
  4. 시연 중 쓸 검색어 메모: 통합검색 광어 / 선박검색 테슬란 / 빠른찾기 인천 > 중구 + 갑오징어

Ⅲ. 시연 시나리오 — 신규 서비스 임팩트 6장면

Scene 1. 로그인 홈 — “낚시 생활의 시작 화면”1분

임팩트: 예약 사이트가 아니라 ‘개인화된 낚시 홈’ — 내 출조 D-6 리마인드·바다 날씨·찜한 배가 첫 화면에
1
새소식 홈에서 D-6 카드(“다음주 수요일 출조 잊지 않으셨죠?” 어바웃피싱호 8/12) 가리키기 — 클릭하지 않고 소개만“로그인하면 내 출조 일정이 D-데이로 홈에 바로 떠요.”
2
바로 아래 날씨 위젯(인천항 · 파고/수온/풍속/만조) 소개 → “인천항 주말 날씨는?” 클릭 → 포인트 날씨 시트(시간별·주간)“출조 판단에 필요한 바다 날씨·물때가 앱 안에 들어와 있습니다.”
3
시트 우상단 X로 닫기 → 하단 GNB ‘새소식’ 클릭으로 홈 복귀 → 찜한 선박 가로 리스트 잠깐 보여주기상단 배너·이벤트·어종 카드는 절대 클릭하지 않기

Scene 2. 기획전 — “플랫폼이 파는 방식이 달라졌다”1분

임팩트: 단독 확보 좌석·테마 기획전 커머스
1
홈 바로가기에서 ‘광어예약’ 클릭 → 기획전 “미터급 대광어의 귀환” (충남/인천 탭, 선박 카드 그리드)“시즌 어종별로 기획전을 만들어 단독 물량을 팝니다.”
2
지역 탭 ‘인천’ 클릭 → 리스트 전환 확인 → 좌상단 ← 클릭으로 홈 복귀쭈갑 기획전을 보여줄 경우 첫 줄 4척까지만(둘째 줄에 버스 사진 선박 있음)

Scene 3. 탐색 지도 — “전국 낚시 데이터가 한 장의 지도에”2분

임팩트: 조황·포인트·선박·CCTV·낚시용품점 5개 레이어 실시간 지도 (신규 서비스의 간판)
1
하단 GNB ‘탐색’ 클릭 → 기본 조황 모드: 전국에 어종 마커·클러스터 숫자“회원과 선사가 올린 조황이 실시간으로 지도에 쌓입니다.”
2
상단 칩을 차례로 선박 → CCTV → 낚시용품점 → 포인트 클릭 — 레이어가 바뀌는 모습 자체가 데모 포인트
3
포인트 모드에서 서해의 ★ ‘백아도’ 마커 클릭 → 포인트 시트: 조황 기록 → 물때(조류세기·간만조·수온 추이) → 날씨 탭 순서로 클릭“포인트마다 조황 이력과 물때·날씨가 붙어 있어요.”
4
X 닫기 → 칩 ‘선박’ 클릭 → 인천 쪽 닻 아이콘 ‘진두선착장’ 클릭 → ‘선박’ 탭(항구 소속 배 리스트)과 ‘물때’·‘날씨’ 탭만 시연이 시트의 ‘조황’ 탭은 클릭 금지(에러 문구) · ‘길안내’도 금지(위치권한 토스트)
5
(선택) X 닫기 → 칩 ‘조황’ → 하단 ‘조황/조과 등록’ 클릭 → 지도 핀 “원하는 위치를 지정해 주세요” 화면까지 보여주고 ‘취소’ 클릭“유저 조과 등록도 위치 기반으로 받습니다.” (등록 제출은 하지 않음)

Scene 4. 통합검색 — “한 검색어로 어종·선박·조황까지”1분

임팩트: 검색 한 번에 전 콘텐츠 크로스 검색 + 실시간 검색순위
1
우상단 돋보기 클릭 → 실시간 검색순위(매일 09시 업데이트) 잠깐 소개
2
검색창에 광어 입력 후 Enter → 결과 헤더 강조: 전체 2,117 · 업체 374 · 선박조황 535 · 회원조황 1,207“어종 사전부터 예약 가능 선박, 조황 글까지 한 번에 걸립니다.”
3
‘업체’ 탭 클릭 → 광어 취급 374척 리스트 스크롤 2~3번 → 좌상단 ← 클릭‘선박조황’ 탭·어종 카드(넙치)는 클릭 금지

Scene 5. 예약 풀 플로우 — “검색부터 결제까지 60초” (하이라이트)3분

임팩트: 신규 서비스의 본체. 검색 → 상세 → 날짜/인원 → 쿠폰 자동 할인 → 결제 직전까지 무중단
1
하단 GNB ‘출조’ 클릭 → 상단 선박 검색창에 테슬란 입력 후 Enter → 1건: 테슬란호 (인천 제물포구 · 90,000원~)“어바웃피싱호”로 검색하지 말 것(0건 나옴)
2
테슬란호 카드 클릭 → 선박 상세: 사진·9.77t·최대 20명·어종 태그 소개 → 쿠폰 영역: ‘다운로드’ 버튼이 보이면 클릭 → “쿠폰이 발급되었습니다” 토스트 (이미 ‘보유중’이면 “쿠폰이 계정에 있습니다” 정도로 멘트만)
3
캘린더에서 파란 날짜 ‘8월 22일(토)’ 클릭 → 아래 상품 카드: 백조기 90,000원 · 20자리 남음 · 04:30~16:30 · 자리배정 추첨“날짜별 상품·잔여석이 실시간입니다.”
4
‘예약하기 (출조일 3일전까지 무료 취소)’ 클릭 → 예약 상품 화면에서 인원 ‘+’ 두 번(대인 2명) → 하단 ‘예약 정보 입력하기’ 클릭“잔여석보다 많은 인원은 아예 눌리지 않게 막혀 있습니다.” (멘트만, 20번 클릭 시연은 생략)
5
예약 접수(결제) 화면: 예약자 자동 입력 확인 → ‘사용할 수 있는 쿠폰이 1개 있어요’ 클릭 → ‘단체예약 10% 쿠폰’ 선택 → 결제 금액 박스가 상품 180,000 / 쿠폰 -18,000 / 총 162,000원으로 바뀌는 순간 강조“쿠폰이 결제 금액에 즉시 반영됩니다.”
6
결제수단 5종(퀵계좌이체·카드·네이버페이·토스페이·카카오페이) 보여주기 → 약관 행 왼쪽 체크 클릭 → 하단 CTA가 “162,000원 결제하기 · 쿠폰 적용 완료”로 활성되는 것 확인 → 여기서 멈춤결제 버튼은 누르지 않는다. 화면 최하단 ‘고객센터 바로가기’도 금지“실 결제는 PG 테스트 승인 관계로 여기까지 보여드립니다.”
7
좌상단 ← 를 두 번 눌러 선박 상세 → 출조 홈으로 복귀 (브라우저 뒤로가기 금지)

Scene 6. 마이 — “예약 관리와 9월 예고” (클로징)1~2분

임팩트: 예약 이후 경험 + 9/9 대개편 예고로 마무리
1
하단 GNB ‘마이’(프로필 아이콘) 클릭 → ‘예약 내역’ 클릭 → 예정 탭의 D-6 어바웃피싱호 → ‘예약 내역 자세히 보기’ 클릭 → 상품·예약·결제·오시는 길 정보‘예약취소’ 버튼은 절대 클릭 금지 (홈 D-6 데모 데이터가 사라짐)
2
← 복귀 → ‘알림 설정’ 클릭 → 서비스/마케팅 토글과 야간 알림 차단(22:00~08:00) 소개‘관심낚시 설정’·‘고객센터 바로가기’·‘회원탈퇴’ 금지
3
← 복귀 → ‘공지사항’ 클릭 → 최상단 ‘어바웃피싱 업데이트 소식 📬’(2026.8.5) 클릭 → “9월, 어바웃피싱이 한층 새로워집니다 · 9월 9일 만나보세요” 배너로 클로징“오늘 보신 것이 9월 9일 정식 오픈 버전입니다.”

Ⅳ. 돌발 상황 대응

상황대응
흰 화면이 몇 초 지속기다린다(만지지 않기). 10초 넘으면 하단 GNB 아무 탭 → 새소식 탭 순서로 이동
실수로 404(고객센터)에 들어감브라우저 뒤로가기 1번 → 흰 화면 수 초 후 원래 화면 복원됨. “테스트 서버 페이지입니다” 멘트로 넘기기
조황 사진이 회색으로 나옴“이미지 서버 반영 중” 멘트 후 다른 글로 스크롤 (사전 점검에서 정상 글 위치 확보해 둘 것)
토스트가 닫기(X)를 가림2~3초 기다렸다가 X 클릭
쿠폰이 ‘보유중’으로 떠서 다운로드 장면 불가바로 Scene 5-5의 ‘쿠폰 적용’으로 넘어가면 임팩트 동일
질문: “지도 거리(km)가 왜 이래?”“위치권한 기준 직선거리라 브라우저 설정에 따라 달라집니다” (기준 불일치 이슈는 수정 예정)
근거: 2026-08-06 test-platform 전 뎁스 실측(QA 리포트 별도). 이 대본의 모든 클릭 경로·검색어·화면 결과는 당일 실제 검증된 것만 사용. 단 이미지 CDN 503과 쿠폰 보유 상태는 시점에 따라 달라질 수 있어 사전 점검 항목에 포함.
